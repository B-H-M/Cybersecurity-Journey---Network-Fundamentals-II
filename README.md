## 📚 Course Summary

### 1. Introduction to Network Fundamentals II

Expanded my understanding of networking principles, focusing on network communication, protocols, and infrastructure.

**SOC Relevance:** Understanding how networks function provides the foundation for identifying unusual traffic patterns and investigating security incidents.

### 2. Basic Networking Concepts

Reinforced essential concepts relating to network communication, connectivity, addressing, and data transmission.

**SOC Relevance:** Supports effective troubleshooting, traffic interpretation, and identification of potential network anomalies.

### 3. Virtual Local Area Network (VLAN)

Learned how VLANs logically segment networks into separate broadcast domains, improving network organization, traffic management, and security.

**SOC Relevance:** Network segmentation can restrict unauthorized communication and reduce opportunities for lateral movement.

### 4. Virtual Private Network (VPN)

Explored how VPNs provide secure remote connectivity through encrypted communication tunnels.

**SOC Relevance:** VPN knowledge supports investigations involving remote access, suspicious authentication attempts, and unauthorized connections.

### 5. Network Protocols

Strengthened my understanding of communication protocols, including TCP, UDP, HTTP, HTTPS, DNS, and DHCP.

**SOC Relevance:** Protocol knowledge helps analysts interpret network logs and identify suspicious communication patterns.

### 6. OSI Reference Model

Revisited the seven layers of the OSI model and their roles in network communication.

| Layer | Name | Primary Function |
|---|---|---|
| 7 | Application | Application-level network services |
| 6 | Presentation | Data representation and encryption |
| 5 | Session | Communication session management |
| 4 | Transport | End-to-end data delivery |
| 3 | Network | IP addressing and routing |
| 2 | Data Link | MAC addressing and frame delivery |
| 1 | Physical | Transmission of bits and signals |

**SOC Relevance:** Provides a structured framework for troubleshooting network issues and investigating suspicious traffic.

### 7. Media Access Control (MAC) Address

Studied MAC addressing, its structure, and its role in identifying network interfaces on local networks.

**SOC Relevance:** Helps with device identification, local network investigations, and understanding MAC spoofing.

### 8. Address Resolution Protocol (ARP)

Learned how ARP maps IPv4 addresses to MAC addresses and how ARP requests and replies operate within local networks.

**SOC Relevance:** Understanding ARP supports the investigation of ARP spoofing, ARP poisoning, and potential man-in-the-middle attacks.

### 9. Internet Protocol (IP)

Developed a deeper understanding of IPv4 addressing, packet structure, routing, Time to Live (TTL), and header checksums.

**SOC Relevance:** Supports packet analysis, traffic investigation, and identification of suspicious source and destination addresses.

### 10. Internet Control Message Protocol (ICMP)

Explored how ICMP supports network diagnostics and error reporting through messages such as Echo Request, Echo Reply, Destination Unreachable, and Time Exceeded.

**SOC Relevance:** Helps identify network scanning, connectivity issues, and unusual ICMP activity.

### 11. Routing

Studied how routers forward packets between networks using routing tables, static routes, dynamic routing, and routing protocols such as OSPF, RIP, and EIGRP.

**SOC Relevance:** Helps analysts understand network traffic paths, troubleshoot connectivity issues, and investigate routing anomalies.
